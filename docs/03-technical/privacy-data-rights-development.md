# 隐私安全与数据权利开发设计方案

## 1. 模块定位

隐私安全与数据权利用于让用户理解、导出、撤销和删除自己的健康数据授权。它贯穿账号、家庭共享、报告分享、设备接入、AI 处理和医生/顾问视图，是所有健康数据业务的底线能力。

状态：`Future`，其中分享撤销、设备断开、访问日志应随对应模块同步实现。

## 2. 业务方案

### 用户可执行权利

| 权利 | 说明 |
|---|---|
| 数据导出 | 导出用户健康档案、记录、报告和授权日志 |
| 账号注销 | 删除或匿名化账号相关数据 |
| 授权管理 | 查看和撤销家庭、设备、医生/顾问、报告分享授权 |
| 访问日志 | 查看谁在什么时候访问了哪些共享数据 |
| 敏感数据脱敏 | 手机号、设备 token、报告链接等不明文展示 |
| AI 数据说明 | 查看 AI 使用了哪些数据类型生成建议 |

## 3. 数据分类

| 等级 | 数据 | 处理要求 |
|---|---|---|
| 普通账号数据 | 昵称、头像、语言偏好 | 可展示，可编辑 |
| 健康敏感数据 | 体重、睡眠、用药、体检、设备指标 | 默认私密，分享需授权 |
| 高敏凭证 | refresh token、设备 token、支付凭证 | 加密存储，不返回客户端 |
| 审计数据 | 登录、分享、后台操作、医生访问 | 不允许用户直接修改 |

## 4. 核心流程

### 数据导出

```text
用户发起导出
  -> 二次验证
  -> 创建 export job
  -> 后台生成文件
  -> 短期下载链接
  -> 到期自动失效
```

### 账号注销

```text
用户申请注销
  -> 展示影响范围
  -> 二次验证
  -> 冷静期或立即执行策略
  -> 撤销 token / 设备 / 分享
  -> 删除或匿名化业务数据
  -> 写入审计日志
```

### 撤销授权

适用于家庭共享、报告链接、设备接入、医生/顾问授权：

- 状态改为 revoked。
- 写入 `revoked_at`。
- 删除相关缓存。
- 后续访问返回权限错误。
- 审计日志可追溯。

## 5. 数据库设计

所有表必须包含 `created_at`、`updated_at`。

| 表 | 说明 |
|---|---|
| `privacy_consents` | 用户隐私同意记录 |
| `data_export_jobs` | 数据导出任务 |
| `account_deletion_requests` | 账号注销申请 |
| `authorization_registry` | 授权总表，聚合家庭、设备、报告、医生授权 |
| `user_access_logs` | 用户侧访问日志 |
| `sensitive_data_access_logs` | 敏感数据访问日志 |
| `data_retention_policies` | 数据保留策略 |

## 6. API 设计

| 接口 | 说明 |
|---|---|
| `GET /privacy/authorizations` | 授权总览 |
| `DELETE /privacy/authorizations/:id` | 撤销授权 |
| `GET /privacy/access-logs` | 访问日志 |
| `POST /privacy/data-exports` | 创建数据导出任务 |
| `GET /privacy/data-exports/:id` | 查询导出状态 |
| `POST /privacy/account-deletion` | 申请注销 |
| `POST /privacy/account-deletion/cancel` | 取消注销 |
| `GET /privacy/consents` | 同意记录 |

## 7. UI 原型

新增原型：`UI/web-privacy-rights.svg`。

页面结构：

- 授权总览：家庭、设备、报告、医生/顾问。
- 最近访问记录。
- 数据导出任务。
- 账号注销入口。
- 隐私同意版本。

App 侧在“我的 - 隐私安全”中增加同样的信息架构，移动端优先展示授权撤销和访问日志。

## 8. 验收标准

- 用户可以查看所有外部授权。
- 撤销授权后对应业务接口立即无权限。
- 数据导出任务可查询状态，下载链接过期失效。
- 注销流程撤销 token、设备连接和分享链接。
- 隐私相关表均具备 `created_at`、`updated_at`。
