# 产品业务方案

## 1. 产品定位

HealthGuard 是一个轻量、可信、可扩展的健康管理应用。它不以“记录越多越好”为目标，而是围绕用户本人健康状态，把记录、趋势、建议和复盘整理成可执行的日常闭环。

## 2. 目标用户

| 用户 | 诉求 | 典型场景 |
|---|---|---|
| 普通用户 | 看懂今天健康状态，获得可执行建议 | 登录后查看健康分、补水、记录饮食和运动 |
| 慢病/控糖/减脂用户 | 长期追踪关键指标 | 查看体重、心率、饮食、运动趋势 |
| 家庭成员 | 关注家人健康状态 | 接收授权数据、查看报告、提醒用药 |
| 医生/健康顾问 | 快速理解用户近期状态 | 查看报告、趋势和异常摘要 |
| 运营/管理端 | 管理内容、服务、用户权益 | Pro 会员、报告模板、专家服务配置 |

## 3. 核心业务闭环

```text
登录 / 注册
  -> 首次建档
  -> 首页健康分
  -> 记录饮食 / 运动 / 饮水 / 睡眠 / 用药
  -> 数据趋势
  -> AI 建议
  -> 报告 / 分享 / 家庭协作
  -> 目标调整
```

## 4. 业务阶段

### Phase 1 MVP - Current

- 手机号验证码登录。
- 基础档案：昵称、年龄、性别、身高、体重、目标。
- 饮食记录与营养汇总。
- 运动记录与热量消耗。
- 日汇总与今日仪表盘。

### Phase 2 近期增强 - Next

- 数据趋势：体重、健康分、心率、热量、饮水、睡眠等周/月/年视图。
- AI 健康建议：基于近期记录生成睡眠、饮水、运动、饮食建议。
- 我的页：健康档案、报告、目标设定、通知提醒、显示设置、隐私安全。
- 报告导出：PDF 报告、分享医生或家人。

### Phase 3 智能化 - Future

- 拍照识别饮食并估算营养。
- 自然语言记录饮食、运动、症状或陪伴上下文。
- 周报/月报与长期趋势解释。
- companion context 作为生活方式解释层参与 AI 建议。

### Phase 4 家庭与设备生态 - Future

- 家庭成员加入与数据授权。
- Garmin 等可穿戴设备接入，减少手动记录成本。
- 医生/健康顾问协作视图。

### Phase 5 商业化 - Future

- Pro 会员解锁深度报告和专属计划。
- 专家咨询、组织账号、健康管理服务包。

## 5. 业务边界

- 产品主语始终是用户本人健康管理。
- AI 建议是健康管理辅助，不提供诊断、处方或急救判断。
- companion context 只解释用户情绪、规律性和活动意愿，不扩展为宠物健康平台。
- 家庭共享必须基于用户授权和可见范围控制。
- Garmin 数据必须基于用户显式授权接入，只用于健康展示、趋势分析、报告和建议，不用于训练外部模型。

## 6. 关键业务指标

- 建档完成率。
- 7 日记录留存率。
- 日汇总查看率。
- AI 建议采纳率。
- 报告导出/分享次数。
- 家庭成员邀请成功率。
