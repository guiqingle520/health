# 验收与测试计划

## 1. 测试目标

- 验证登录、建档、记录、汇总、仪表盘主路径稳定。
- 验证 Next 功能开发时不会破坏 Current 行为。
- 为产品、研发、测试提供一致的验收清单。

## 2. Current 后端 e2e 场景

当前 `apps/backend/test/app.e2e-spec.ts` 已覆盖：

- 登录并返回用户、access token、refresh token。
- 未建档用户获取 `/health/profiles/me` 返回 404。
- 当前用户建档成功。
- 饮食记录写入成功。
- 运动记录写入成功。
- 鉴权查询饮食历史成功。
- 鉴权查询运动历史成功。
- 未鉴权查询历史返回 401。
- 获取日汇总成功。
- 获取今日仪表盘成功。

## 3. MVP 验收

### 登录与建档

- 正确手机号和验证码可以登录。
- 未建档进入建档页。
- 已建档进入首页。
- 非法档案字段不能提交。

### 饮食记录

- 支持四类餐次：breakfast、lunch、dinner、snack。
- 营养字段必须为非负数。
- 写入后日汇总热量和营养更新。

### 运动记录

- 支持 aerobic、strength、flexibility。
- 时长必须大于 0。
- 写入后日汇总运动消耗更新。

### 仪表盘

- 展示健康分、档案摘要、卡片指标、AI 洞察、日汇总。
- 无记录时仍能返回默认汇总。
- 刷新失败时显示重试。

## 4. Next 功能验收

### 数据趋势

- 周/月/年切换正确。
- 无数据显示空态。
- 指标异常显示文字标签。
- 趋势接口返回空 points 时页面不崩溃。

### AI 建议

- 建议包含类型、标题、原因、动作。
- 采纳、稍后、忽略状态可更新。
- AI 文案不输出诊断、处方或急救判断。

### 我的页

- 档案入口可达。
- 报告、目标、通知、隐私、安全入口可达。
- 退出登录后回到登录页。

### Garmin 设备接入

- 未连接时展示 Garmin 授权入口和同步指标说明。
- OAuth state 校验失败时不能创建设备连接。
- 授权成功后展示 `connected` 状态和最近同步时间。
- backfill 成功后标准化指标写入趋势数据源。
- webhook 重复推送不会产生重复指标事件。
- token 失效且刷新失败时标记为 `reauth_required`。
- 断开连接后停止同步，客户端不再展示为已连接。

### 报告

- 可按周/月生成报告摘要。
- PDF 导出失败时给出可重试状态。
- 分享前必须展示授权对象和数据范围。

## 5. 安全与权限

- 用户不能读取他人档案、记录、报告。
- 家庭共享必须校验授权范围。
- refresh token 失效后不能继续刷新。
- 退出登录后本地 token 清除。

## 6. 回归清单

- `npm run backend:build`

- 文档链接检查：`docs/README.md` 中所有相对链接可打开
