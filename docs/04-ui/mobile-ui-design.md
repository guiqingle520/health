# 移动端 UI 设计

## 1. 设计目标

- 让用户快速理解今日健康状态。
- 降低记录门槛。
- 支持中老年用户阅读，字号和触控区域足够大。
- 和 `UI/` 原型保持一致，采用浅绿灰背景、白色圆角卡片、青绿色高亮、底部胶囊导航。

## 2. 页面结构

### 登录页

- 顶部品牌 Logo 与简短说明。
- 手机号输入。
- 验证码输入与获取验证码按钮。
- 登录并继续主按钮。
- 协议与隐私政策勾选。

登录页不显示底部导航。

### 建档页

- 标题：完善健康档案。
- 建档进度。
- 基础字段：昵称、年龄、身高、体重、性别、目标。
- 保存后进入首页。

建档页不显示底部导航。

### 首页

- 健康分卡片。
- 今日核心指标：步数、睡眠、饮水、热量。
- companion context 轻量摘要。
- AI 快捷提醒。
- 底部导航选中：首页。

### 数据趋势

- 标题：数据趋势。
- 周/月/年切换。
- 指标趋势卡：体重、静息心率，后续扩展健康分、饮水、睡眠。
- 异常提示以标签展示，不只依赖颜色。

### AI 建议

- 拍照记录饮食主入口。
- 搜索食物 / 问 AI 输入框。
- 今日 AI 推荐卡片。
- 建议卡包含类型、标题、原因、采纳按钮、稍后再说按钮。

### 我的

- 个人资料卡。
- Pro 会员入口。
- 健康档案分组。
- 数据与报告分组。
- 家庭与共享分组。
- 设置与偏好分组。
- 设备与数据源：Garmin 连接状态、最近同步时间、同步指标、断开授权。
- 帮助与支持分组。
- 退出登录。

## 3. 组件规范

- 页面背景：浅绿灰。
- 手机边框原型：深绿，仅用于原型展示。
- 卡片：白色，圆角 20-24，轻投影。
- 主色：青绿色，用于激活态、主按钮和关键 icon。
- 警示色：柔和橙色，用于异常、提醒。
- 底部导航：胶囊容器，四个入口：首页、数据、AI 建议、我的。

## 4. 状态设计

- 加载态：卡片骨架屏或中心 loading。
- 空态：说明当前无数据，并提供记录入口。
- 错误态：页面内提示 + 重试按钮。
- 未建档态：首页接口返回档案缺失时跳转建档。
- 无网络态：保留本地缓存数据并提示更新时间。

## 6. 可访问性

- 关键文字不小于 13px。
- 按钮高度不小于 44px。
- 图表异常需要文字标签。
- 颜色对比满足浅色背景可读性。
